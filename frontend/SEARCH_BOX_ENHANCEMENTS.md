# 搜索框增强功能说明

## 修改内容

### 1. 边框样式优化
- **去除所有边框**：移除了搜索框的四周边框
- **只保留下边框**：使用2px粗的下边框作为视觉焦点
- **颜色状态**：
  - 默认状态：灰色下边框 (`divider` 颜色)
  - 悬停状态：稍深的灰色边框
  - 聚焦状态：主色调蓝色边框

### 2. 可伸缩长度效果
- **默认宽度**：400px（未聚焦时）
- **聚焦时宽度**：600px（聚焦时自动扩展）
- **平滑过渡**：使用 `cubic-bezier(0.4, 0, 0.2, 1)` 缓动函数实现流畅的动画效果
- **过渡时间**：300ms

### 3. 交互增强功能
- **聚焦状态管理**：使用 `searchFocused` 状态跟踪输入框是否获得焦点
- **图标颜色变化**：
  - 未聚焦：图标为次要文本颜色
  - 聚焦时：图标变为主色调蓝色
- **清除按钮**：当搜索框有内容时显示清除按钮（×图标）
- **高级搜索按钮**：始终显示筛选图标，点击打开高级搜索抽屉

### 4. 视觉反馈
- **悬停效果**：鼠标悬停时边框颜色变化
- **聚焦效果**：输入框获得焦点时边框变蓝并扩展宽度
- **图标交互**：所有图标都有悬停颜色变化效果

## 技术实现

### 状态管理
```typescript
const [searchFocused, setSearchFocused] = useState(false);
```

### 样式关键代码
```typescript
sx={{
  maxWidth: searchFocused ? 600 : 400,
  borderBottom: '2px solid',
  borderColor: searchFocused ? 'primary.main' : 'divider',
  transition: 'all 0.3s cubic-bezier(0.4, 0, 0.2, 1)',
  '&:hover': {
    borderColor: searchFocused ? 'primary.main' : 'grey.400',
  },
}}
```

### 事件处理
- `onFocus={() => setSearchFocused(true)}` - 输入框获得焦点时
- `onBlur={() => setSearchFocused(false)}` - 输入框失去焦点时
- `onClick={() => setSearchQuery('')}` - 清除按钮点击时

## 用户体验改进

### 1. 视觉层次
- 简洁的下边框设计减少视觉干扰
- 聚焦时的扩展效果引导用户注意力
- 颜色变化提供明确的交互反馈

### 2. 操作便利性
- 清除按钮方便用户快速清空搜索内容
- 高级搜索按钮始终可见，便于访问更多筛选选项
- 平滑的动画过渡提升使用体验

### 3. 响应式考虑
- 宽度变化在合理的范围内，避免破坏布局
- 在小屏幕上依然保持良好的可用性
- 图标大小和间距适配不同设备

## 效果预览

- 宽度：400px
- 边框颜色：灰色
- 图标颜色：灰色

### 聚焦状态
- 宽度：600px（扩展200px）
- 边框颜色：蓝色

- 显示清除按钮（×图标）

- 用户可以快速清空或提交搜索
